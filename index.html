Deploy to LINE (LIFF)

To run inside LINE — with auto-login and "Send to LINE chat" — you need a public HTTPS URL and a free LINE Developers account.

1. Host the file

Drag receipt-splitter.html onto Netlify Drop. Free, no signup, get an HTTPS URL in seconds.

2. Create a LIFF app

Go to LINE Developers Console → create a Provider → create a LINE Login channel → LIFF tab → Add new.

  • Endpoint URL: Netlify URL from step 1
  • Size: Full
  • Scopes: profile, openid, chat_message.write

3. Save your LIFF ID

Paste your LIFF ID (e.g. 2001234567-AbCdEfGh):

4. Open in LINE

Share https://liff.line.me/YOUR-LIFF-ID in any LINE chat → tap to launch the app inside LINE.

Without a LIFF ID

Works as a regular web app too — only "Send to LINE chat" falls back to copy-to-clipboard.
